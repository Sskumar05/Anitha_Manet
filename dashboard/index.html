⚙️ Algorithm Design

Standard AODV vs Energy-Aware AODV — key differences

STANDARD

AODV Protocol

  • 🔴 Route selection based on first reply (lowest latency)
  • 🔴 No energy awareness — routes through dying nodes
  • 🔴 Frequent route breaks under high mobility → heavy RREQ flooding
  • 🔴 Battery drain concentrated on few hub nodes
  • 🔴 Re-discovery delay spikes when a route collapses
  • 🔴 High routing overhead at speeds > 10 m/s
Enhanced
ENHANCED

eAODV — Energy-Aware AODV

  • ✅ Route selection via energy-weighted RREP scoring
  • ✅ Attaches BasicEnergySource model to each NS-3 node
  • ✅ Penalises low-battery next-hops; prefers energy-rich nodes
  • ✅ Energy threshold trigger proactive local route repair
  • ✅ Balanced battery load extends network lifetime by ~22%
  • ✅ Lower re-discovery cost → reduced overhead at all speeds
